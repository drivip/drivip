# Diseño UI/UX — Drivip
## Filosofía de diseño
Drivip debe sentirse familiar para el conductor de moto taxi venezolano y moderno para el cliente. La referencia visual es Didi: colores vivos, mapas protagonistas, acciones claras.

## Paleta de colores
- Primario: #6B21A8 (Púrpura - Botones principales, header, CTAs)
- Secundario / Acento: #FF7733 (Naranja vibrante - Badges, iconos activos, highlights)
- Fondo: #191B1E (Carbón oscuro nocturno)
- Superficie: #1A2647 (Carbón claro, tarjetas, modales elevadas)
- Texto: #FFFFFF (Blanco de alto contraste)
- Texto secundario: #94A3B8 (Gris azulado)
- Éxito: #22C55E (Verde - Confirmaciones, pagos completados)
- Error: #EF4444 (Rojo)
- Advertencia: #FACC15 (Amarillo - Alertas, Pago Móvil pendiente)

## Tipografía
- Títulos: Inter / Poppins Bold
- Cuerpo: Inter Regular
- Datos / Métricas / Tarifas / Distancias: JetBrains Mono
